RHYMEWEAVER UNIFIED WORK HUB
================================

FASTEST HP SETUP
1. Keep this whole folder together.
2. Double-click MAKE_DESKTOP_SHORTCUT.cmd one time.
3. After that, use the new RhymeWeaver Unified Work Hub icon on the Desktop.

NO SHORTCUT NEEDED
Double-click START_HERE.html or OPEN_RHYMEWEAVER_WORK_HUB.cmd.

FIRST RUN
1. Open INTAKE.
2. Select files or paste text.
3. Pick Alliteration Phrase Archive, Grow the Word Bank, or General Clean.
4. Press PROCESS & STAGE.
5. Inspect CLEAN, REVIEW, DUPLICATES, and A-Z VIEW.
6. Press APPROVE CLEAN TO LOCAL MASTER only when the clean count looks right.
7. Open SEARCH or download the master and process log.

HOW THE BIG LIST GROWS
The sealed base contains 83,925 archive words. It is never overwritten.
Use Grow the Word Bank to add new word lists. Approved additions are saved locally in the browser and appear in Unified Search. Export HUB BACKUP JSON regularly so the local additions can be restored on another computer or after browser cleanup.

SAFETY
Original files are only read. Review and duplicate lines are preserved as downloads. Master updates are additive and deduplicated.

TOOLS
All 73 manifest HTML builds are in the tools folder and open from the 73 TOOLS chamber.

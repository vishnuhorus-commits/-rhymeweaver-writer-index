# RhymeWeaver Writer Index

A set of offline, single-file HTML tools for organizing rhymes, alliteration, and text collections. Each tool runs entirely in the browser — no server or install required, just open the file.

## Tools

- **[index.html](index.html)** — RhymeWeaver Writer Index. Search clean text, root words, rhyme keys, sources, or A-Z letters, and pull results into a draft. Produces merged, deduplicated, searchable outputs.
- **[phon-rhyme-lab.html](phon-rhyme-lab.html)** — Phon Rhyme Lab. A CMUdict-based pronunciation and rhyme engine for finding perfect rhymes, alliteration lines, and writing prompts.
- **[automation-hub.html](automation-hub.html)** — RhymeWeaver Automation Hub. A control-center page for jumping between the other tools without losing your place.
- **[az-folder-automator.html](az-folder-automator.html)** — A-Z Folder Automator. Builds an A-Z folder package as a single ZIP, since the browser can't create folders directly in iPad's Files app — unzip it to get the folders already organized.

## Usage

Open any `.html` file directly in a browser (works well on iPad/mobile — no install needed).
